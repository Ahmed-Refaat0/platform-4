# بوابة النظام الأكاديمي | Academic Faculty Portal

بوابة أكاديمية تفاعلية بتصميم عصري ومتناسق يدعم الوضع الداكن والفاتح واللغة العربية والإنجليزية.

## 🎨 المميزات

- ✅ **تبديل الوضع الداكن / الفاتح** — تصميم متناسق مع الأخضر الأكاديمي
- ✅ **تبديل اللغة عربي / إنجليزي** — مع دعم كامل لـ RTL و LTR
- ✅ **تصميم متجاوب** — يتناسب مع جميع أحجام الشاشات
- ✅ **بطاقات تفاعلية** — مع تأثيرات هوفر وأنيميشن ناعمة
- ✅ **نوافذ حوار** — تقويم، إشعارات، ملف شخصي

## 🎨 نظام الألوان

| العنصر | الوضع الفاتح | الوضع الداكن |
|--------|-------------|-------------|
| الخلفية | `#ffffff` | `#121514` |
| القائمة الجانبية | `#132821` | `#0d1815` |
| العنصر النشط | `#244d3f` | `#173328` |
| اللون المميز | `#34d399` | `#57f1db` |
| البطاقات | `#ffffff` | `#1b221f` |

## 🚀 التشغيل

```bash
# افتح المجلد وشغل سيرفر محلي
python -m http.server 8085

# ثم افتح في المتصفح
# http://localhost:8085
```

## 🛠️ التقنيات

- **HTML5** — هيكل دلالي (Semantic)
- **TailwindCSS CDN** — تنسيق سريع ومتجاوب
- **Google Material Icons** — أيقونات عصرية
- **Cairo + Inter Fonts** — خطوط عربية وإنجليزية مصقولة
- **Vanilla JavaScript** — منطق تبديل المظهر واللغة
